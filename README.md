# ThiranX

> AI-powered career intelligence platform for developers.

ThiranX is a developer career intelligence platform that helps users understand their current progress, identify what they should learn next, and build a structured path toward their career goals.

It combines **AI-generated learning roadmaps, task tracking, GitHub activity, LeetCode statistics, analytics, and AI-powered insights** into a single platform.

---

## Overview

Developers often use multiple platforms to manage different parts of their learning journey.

- GitHub shows development activity.
- LeetCode shows problem-solving progress.
- Learning platforms provide educational content.
- Task managers track what needs to be completed.
- AI tools provide generic answers and roadmaps.

The problem is that these systems are disconnected.

**ThiranX connects these signals.**

Instead of only showing raw statistics, ThiranX attempts to turn those signals into actionable information:
